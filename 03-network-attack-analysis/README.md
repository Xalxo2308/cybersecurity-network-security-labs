# Network Attack Analysis

## Objective

Study network attack techniques in a controlled academic cybersecurity laboratory environment and analyse their effects on network communication.

## Laboratory Activities

The laboratory work covered practical investigation of network attack and security concepts using isolated virtual-machine environments.

### Attack Analysis

- Investigated network attack behaviour using controlled laboratory systems.
- Examined network traffic generated during security exercises.
- Used packet-analysis techniques to understand network communication.
- Investigated DNS spoofing concepts using NetWag/NetWox in an authorised laboratory environment.
- Analysed how manipulated DNS responses can affect hostname resolution and network communication.

## Tools

- Ubuntu Linux
- Wireshark
- NetWag / NetWox
- Virtual machines
- Command-line networking utilities

## Skills Demonstrated

- Network attack analysis
- DNS security
- Packet analysis
- Network troubleshooting
- Linux command-line tools
- Virtualised security laboratories
- Security analysis

## Security Context

All activities were performed in controlled academic laboratory environments for educational purposes. No unauthorised systems were targeted.
