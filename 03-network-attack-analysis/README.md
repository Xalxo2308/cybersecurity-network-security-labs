# Network Attack & Protocol Analysis

## Objective

Study network attack behaviour and analyse protocol-level effects in a controlled cybersecurity laboratory environment.

## Attack Scenarios

### ARP Cache Poisoning

Analysed changes in MAC-address mapping following a controlled ARP cache-poisoning scenario.

### ICMP Redirect

Analysed ICMP Redirect messages and their effect on network routing behaviour.

### TCP RST

Investigated TCP reset behaviour affecting Telnet and SSH connections.

### ICMP Blind Connection Reset

Analysed the effect of ICMP messages on active Telnet and SSH connections.

### ICMP Source Quench

Observed the simulated traffic-management effect in the laboratory environment.

### TCP Session Hijacking

Analysed a controlled TCP session-hijacking scenario and observed its effect on an active Telnet session.
