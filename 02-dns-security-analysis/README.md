# DNS Security Analysis

## Objective

Investigate DNS behaviour and security weaknesses in a controlled cybersecurity laboratory environment.

## Tools

- Linux / Ubuntu
- `dig`
- Wireshark
- NetWag / NetWox
- DNS

## Activities

- Queried DNS records using `dig`.
- Analysed DNS requests and responses.
- Inspected DNS traffic using Wireshark.
- Performed controlled DNS spoofing exercises.
- Investigated DNS cache-poisoning concepts.
- Used network-security tooling to observe manipulated DNS responses.
- Analysed the resulting network behaviour.

## Key Skills Demonstrated

- DNS protocol analysis
- DNS troubleshooting
- DNS security
- Packet analysis
- DNS spoofing concepts
- DNS cache-poisoning concepts
- Network-security testing
