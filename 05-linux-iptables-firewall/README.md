# Linux iptables Firewall Configuration

## Objective

Configure and test host-based firewall policies on a Linux/Ubuntu virtual machine in a controlled laboratory environment.

## Tools

- Ubuntu / Linux
- iptables
- SSH
- TCP/IP
- Virtual machines

## Activities

- Verified the iptables installation and available commands.
- Inspected existing firewall chains and packet counters.
- Changed the default firewall policy to DROP.
- Tested network connectivity before and after firewall-policy changes.
- Created rules to permit selected traffic while blocking unauthorised traffic.
- Configured SSH access controls.
- Used stateful firewall rules for NEW and ESTABLISHED connections.
- Verified SSH connectivity after applying firewall rules.
- Listed and removed firewall rules during testing.
- Completed a firewall challenge involving HTTP/HTTPS access while blocking other traffic.

## Key Skills Demonstrated

- Linux firewall configuration
- iptables
- Network access control
- Stateful firewall rules
- SSH security
- TCP/IP traffic filtering
- Firewall troubleshooting
- Default-deny security policy
