# Wireshark Network & DNS Traffic Analysis

## Objective

Analyse network traffic at packet level and investigate DNS communication using Wireshark in a controlled Linux laboratory environment.

## Tools

- Wireshark
- Linux / Ubuntu
- DNS
- TCP/IP

## Activities

- Captured network traffic using Wireshark.
- Applied DNS display filters to isolate DNS traffic.
- Inspected DNS queries and responses.
- Examined packet headers and protocol fields.
- Analysed IPv4 and IPv6 traffic.
- Investigated source and destination information.
- Used packet-level analysis to understand network communication behaviour.

## Key Skills Demonstrated

- Packet capture
- Packet filtering
- DNS analysis
- TCP/IP analysis
- Network troubleshooting
- Protocol inspection
- Network traffic interpretation
