# Web & Password Security Fundamentals

## Objective

Explore fundamental web and password-security concepts through controlled academic laboratory exercises.

## Tools

- Wireshark
- John the Ripper
- Linux / Ubuntu
- Web security laboratory environment

## Activities

### Password Security

- Investigated password-security concepts using a controlled laboratory exercise.
- Used John the Ripper as part of the academic password-security exercise.
- Examined different password-cracking approaches.
- Analysed characteristics associated with stronger passwords, including password length, character diversity and avoidance of personal information.

### Web Security

- Analysed HTTP traffic using Wireshark.
- Inspected web objects and application traffic.
- Performed SQL-injection exercises against an intentionally vulnerable laboratory application.
- Studied the security implications of input-validation weaknesses.

### DNS and Host Configuration Security

- Investigated HOST-file modification as part of a controlled security exercise.
- Studied how DNS-related manipulation can affect network communication.

## Key Skills Demonstrated

- Password-security principles
- Wireshark HTTP traffic analysis
- SQL-injection concepts
- Web-security awareness
- Security assessment
- Network-security fundamentals
- Security analysis in controlled environments
