# Snort Intrusion Detection

## Objective

Configure and test a basic network intrusion-detection environment using Snort in a controlled Linux virtual-machine laboratory.

## Tools

- Snort
- Linux / Ubuntu
- Virtual machines
- Local Snort rules
- Network traffic monitoring

## Activities

- Configured the monitored local network for Snort.
- Configured the `HOME_NET` variable for the laboratory network.
- Started and tested the Snort service on the server virtual machine.
- Generated network traffic to test Snort monitoring.
- Observed security alerts generated by Snort.
- Created a local Snort rule for web-service monitoring.
- Tested alert generation associated with Telnet network activity.
- Analysed the resulting security alerts.

## Key Skills Demonstrated

- Intrusion detection
- Network monitoring
- Security alert analysis
- Rule-based detection
- Linux security tooling
- Network traffic analysis
- Basic IDS configuration
